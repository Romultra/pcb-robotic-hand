Servos locked: calibration mode

Sliders are normalized: left = open, right = closed, spanning each finger's calibrated range. Calibrate in the panel below first.

Finger Calibration

Learns each finger's safe travel and stores it on the board (NVS); the firmware then clamps every command to it. Servos hold an absolute position, so once set these values stay valid across power cycles as long as the ropes aren't moved. Needs the DC barrel jack.

  1. Press Power ON.
  2. Tick Calibration mode: this takes control here, removes the safe limits so you can jog freely, and locks the Servos panel above.
  3. Rope slack: jog each finger to its motor end-stops (the “seen” range fills in).
  4. Rope on: jog to the safe most-open pose then Set OPEN; to the safe most-closed pose then Set CLOSED.
  5. Save to board, then untick Calibration mode to enforce the limits and hand control back. Power OFF is the emergency stop.
